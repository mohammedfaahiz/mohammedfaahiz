## About

I build .NET Core backends, REST APIs and optimized databases that process IoT meter data reliably at scale. My work covers smart-meter data decoding, billing engines, real-time dashboards and cloud data synchronization.

At **Raasoft Infotech** I was promoted to **Senior Software Engineer in April 2026** for my work on cloud data sync and the Kiosk application.
